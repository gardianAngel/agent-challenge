I'll break this down into sequential prompts that would get an AI to build this system most effectively. Each prompt is designed to produce working code that builds on the previous components.

```

Create a comprehensive system architecture that includes:

2. Data flow diagrams showing how agents communicate
3. TypeScript interfaces for all data structures
4. Agent orchestration patterns using Mastra's agent framework
5. Real-time data ingestion architecture for blockchain and social media sources

Requirements:
- Must use Mastra.ai framework for agent orchestration
- Include Docker containerization strategy
- Design for deployment on Nosana's decentralized GPU network
- Support for Ethereum, Polygon, Arbitrum, and Solana
- Real-time WebSocket connections for live data

Output: Complete architecture document with TypeScript interfaces, agent definitions, and deployment configuration.
```

## **Phase 2: Data Collection Agents**

### **Prompt 3: Protocol Monitor Agent**
```

The agent must:
1. Connect to multiple blockchain networks (Ethereum, Polygon, Arbitrum)
2. Monitor TVL, utilization rates, and liquidity for protocols: Aave, Compound, Uniswap V3, Curve
3. Use APIs: DefiLlama, Aave API, Compound API, Uniswap Subgraph
4. Detect significant changes (>10% TVL drops, >90% utilization)
5. Store data in time-series format for historical analysis

Implementation requirements:
- Use ethers.js for blockchain interaction
- Implement WebSocket connections for real-time updates
- Include retry logic and rate limiting
- Use Mastra's tool system for external API calls
- Generate structured data outputs for risk calculation

Provide complete working code with API integration examples and error handling.
```

### **Prompt 4: Smart Contract Analyzer Agent**
```
Create a SmartContractAnalyzerAgent that analyzes contract security risks.

1. Fetch contract source code from Etherscan/Polygonscan APIs

Include vulnerability detection regex patterns and scoring algorithms.
```

## **Execution Strategy**

### **Prompt Execution Order:**
1. **Foundation (Prompts 1-2)**: Establish architecture and base framework
2. **Data Collection (Prompts 3-6)**: Build specialized monitoring agents
3. **Intelligence (Prompts 7-8)**: Implement risk calculation and alerts
4. **Interface (Prompts 9-10)**: Create dashboard and deployment
5. **Finalization (Prompts 11-12)**: Testing and documentation

### **AI Development Best Practices:**
- **Iterative refinement**: After each prompt, review output and refine subsequent prompts
- **Code validation**: Test each component before moving to the next
- **Integration checkpoints**: Ensure components work together at each phase
- **Performance optimization**: Focus on real-time processing capabilities
- **Documentation**: Maintain clear documentation for competition judges

### **Success Metrics:**
- **Technical**: All agents functional with real-time data processing
- **Integration**: Seamless multi-agent orchestration via Mastra
- **Deployment**: Successfully running on Nosana network
- **Demo**: Compelling video and live demonstration
- **Documentation**: Complete technical and user documentation

This prompt strategy ensures systematic development while maintaining focus on the competition's specific requirements and judging criteria.
