### **Risk Scoring Algorithm:**
```python
# Risk Score Components (0-100, where 100 = highest risk)
risk_factors = {
    'smart_contract_risk': 0.25,    # Code quality, audits, age
    'market_risk': 0.20,            # Volatility, liquidity
    'governance_risk': 0.15,        # Centralization, timelock
    'technical_risk': 0.15,         # Recent changes, complexity  
    'social_risk': 0.15,            # Community sentiment
    'counterparty_risk': 0.10       # Protocol dependencies
}

def calculate_risk_score(protocol_data):
    weighted_score = sum(
        risk_factors[factor] * score 
        for factor, score in protocol_data.items()
    )
    return min(100, max(0, weighted_score))
```
